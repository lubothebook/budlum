## What a probe can and cannot prove

For each item the script looks for the object the directive names as the
evidence: a gate module registered in `xtask/gates`, a test function, a
document, or the finding count. Three outcomes follow:

* **red**: the evidence object does not exist in the tree.
* **unverifiable**: the object exists, and only a CI run or a rehearsal record
  can say it passed. This script reads neither, so it does not guess.
* **green**: the evidence exists and the verdict is attached. Nothing in this
  tree reaches that state yet.

The report is therefore blunt: zero items are green. That is the true state of
the tree, and it is the state that decides whether an opening is legitimate.
