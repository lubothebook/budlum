# Queue collisions

The measurement section 15.3 assumes a queue the repository does not have. The
directive is written for four agents, one owner per lock path and packages that
merge as their dependencies land. The live state is one base commit, no merged
package, and a queue of open pull requests that overlap.

This file records the overlap instead of asserting it. Regenerate with

    python3 ops/scripts/live_audit.py --queue --write

The numbers come from the GitHub API and from `git merge-base`; nothing here is
estimated. The measurement is deliberately kept out of `--check`, because a CI
checkout has neither the branches nor the token.
